# RehabilitationTracker

Eine JavaFX-Anwendung zur Verwaltung und Dokumentation von Rehabilitationsübungen und Trainingsverläufen.

Das Projekt wurde im Rahmen meines Studiums entwickelt und verbindet objektorientierte Programmierung mit einer grafischen Benutzeroberfläche und lokaler Datenverwaltung.

## Funktionen

- Anmeldung und Registrierung von Benutzern
- Verwaltung von Personen und Rehabilitationsdaten
- Erfassung und Verwaltung von Übungen
- Dokumentation durchgeführter Übungen
- Anzeige des Trainingsverlaufs
- Speicherung und Laden von Daten über lokale Dateien
- Navigation zwischen verschiedenen JavaFX-Ansichten
- Benutzerfreundliche grafische Oberfläche mit FXML

## Technologien

- Java
- JavaFX
- FXML
- Objektorientierte Programmierung (OOP)
- MVC-orientierte Projektstruktur
- File I/O
- Git & GitHub

## Projektstruktur

Das Projekt ist in verschiedene Bereiche aufgeteilt:

- `controller` – Steuerung der Benutzerinteraktionen und Ansichten
- `model` – Datenmodelle und Geschäftslogik
- `view` – FXML-Dateien für die Benutzeroberfläche
- `util` – Hilfsklassen und wiederverwendbare Funktionen
- `graphics` – grafische Ressourcen

## Technische Konzepte

Im Projekt wurden unter anderem folgende Konzepte eingesetzt:

- Klassen und Vererbung
- Generische Datenstrukturen
- Einfach verkettete Listen
- Singleton Pattern
- Event Handling und Lambda-Ausdrücke
- JavaFX Properties und TableViews
- Dateioperationen mit BufferedReader und BufferedWriter
- MVC-Prinzipien
- Trennung von Benutzeroberfläche und Programmlogik

## Ziel des Projekts

Ziel war die Entwicklung einer strukturierten Desktop-Anwendung, mit der Rehabilitationsübungen verwaltet und deren Durchführung dokumentiert werden können.

Dabei lag ein besonderer Fokus auf einer übersichtlichen Softwarearchitektur, objektorientierter Programmierung und der praktischen Anwendung von JavaFX.
